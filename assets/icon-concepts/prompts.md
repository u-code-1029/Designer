# DrillFlow Designer app icon prompts

The three `*-flat.png` files are the final concepts presented for selection. All outputs use a transparent RGBA background and contain no text or watermark.

## A — linked nodes and precision target

```text
Use case: logo-brand
Asset type: refined Windows desktop application icon
Input images: Image 1 is the edit target and conceptual reference.
Primary request: Redesign Image 1 into a much simpler semi-flat Fluent UI vector-like mark. Preserve only the core concept of linked signal nodes surrounding a precision target.
Style/medium: semi-flat geometric icon; 2 to 4 bold solid forms total; rounded, crisp, highly legible at 16 px.
Composition/framing: centered compact triangular network with a simple target center, generous transparent margin, balanced strong silhouette.
Color palette: use only one restrained cyan-to-indigo gradient across the main mark plus at most one small pale accent.
Constraints: genuinely transparent alpha background; no text, letters, numbers, watermark, tile, container, scene, outline clutter, tiny details, gloss, specular highlights, reflections, glass, chrome, bevel, extrusion, 3D depth, inner shadows, bloom, or photographic rendering. Keep overlaps minimal and surfaces matte.
```

## B — command path and control sliders

```text
Use case: logo-brand
Asset type: refined Windows desktop application icon
Input images: Image 1 is the edit target and conceptual reference.
Primary request: Redesign Image 1 into a much simpler semi-flat Fluent UI vector-like mark. Preserve only the core concept of a flowing command path crossing adjustable control sliders.
Style/medium: semi-flat geometric icon; 2 to 4 bold forms total; rounded, crisp, highly legible at 16 px.
Composition/framing: centered compact mark, one thick flowing path integrated with two or three simplified slider rails or knobs, generous transparent margin, strong uncluttered silhouette.
Color palette: use one restrained teal-to-blue gradient on the path, one dark blue neutral for rails, and at most one tiny warm accent.
Constraints: genuinely transparent alpha background; no text, letters, numbers, watermark, tile, container, scene, extra arrows, outline clutter, tiny details, gloss, specular highlights, reflections, glass, chrome, bevel, extrusion, 3D depth, inner shadows, bloom, or photographic rendering. Keep overlaps minimal and surfaces matte.
```

Transparency correction applied to the final B output:

```text
Use case: background-extraction
Asset type: final transparent Windows app-icon concept
Input images: Image 1 is the exact flat icon design to preserve.
Primary request: Remove only the entire white/light-gray checkerboard background and replace it with genuine alpha transparency. Preserve the command-path and slider mark, its shapes, proportions, colors, spacing, and matte flat style unchanged.
Composition/framing: square canvas, centered mark, retain generous margin.
Constraints: the pixels outside the mark must have alpha 0. Do not draw or simulate a checkerboard. No white background, gray background, tile, shadow, text, watermark, gloss, bevel, new detail, or redesign. Output a true 32-bit RGBA PNG with a transparent background.
```

Asset type: refined Windows desktop application icon
Input images: Image 1 is the edit target and conceptual reference.

Color palette: use one restrained indigo-to-magenta gradient for the center and one restrained coral-to-amber gradient for the paired pulses; no other effects.
